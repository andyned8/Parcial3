# Rick and Morty API

## Descripción
Este proyecto consiste en una página web que utiliza la API de Rick and Morty para mostrar información de diferentes personajes de la serie.

La página permite visualizar sus imágenes, nombres, estados, especies, géneros y ubicaciones.

## Tecnologías utilizadas
- HTML5: estructura de la página.
- CSS3: estilos y diseño visual.
- JavaScript: funciones e interacción.
- Vue.js 3: manejo de datos y elementos dinámicos.
- Rick and Morty API: obtención de información de los personajes.

## Funcionalidades
- Cargar personajes automáticamente al iniciar la página.
- Mostrar información de los personajes.
- Buscar personajes por nombre.
- Cambiar entre páginas de personajes.
- Mostrar el estado de cada personaje.
- Consultar información desde una API externa.
